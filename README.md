# final_project_mvp

Setup guide:
1. go to terminal
2. type in 'cd final_project_mvp_collectaflix'
3. type in 'npm install'
4. type in 'npm run dev'
5. click the provided link

This project is based on Discogs but is meant to be a physical media of movies and tv shows.

I'm using teh TMDB api for the app.

If the website is in mobile mode, there will only be a search bar up top and a task bar at the bottom. If the website is in website mode, there all the navigation and search will be at the top.

There are 4 different pages the user can explore.
There is the ExplorePage which is the main page where the user can view the most popular movie and tv show physical medias.
There is the CollectionPage where any items added via the collection button stay.
There is the WantlistPage where any items added via the wantlist button stay.
And lastly there is the the CartPage where all the items added to the cart stay, at the bottom of there is a total for the cart that adds up the price of all the items added.
